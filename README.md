# QuantPulse Website (Free GitHub Pages)

A responsive, static landing page for QuantPulse. It uses plain HTML/CSS/JavaScript and requires no paid hosting or build tools.

## Publish for free with GitHub Pages

1. Sign in to https://github.com
2. Create a **public** repository named `quantpulse-website`.
3. Upload `index.html` to the repository root and commit it to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main`, folder `/ (root)`, and save.
7. Wait for GitHub Pages to publish. Your URL will be similar to `https://YOUR-USERNAME.github.io/quantpulse-website/`.

## Before launch
- Replace the Instagram contact URL in `index.html` if your official handle changes.
- Verify all features and broker integrations you advertise.
- Confirm Plan 2 fee terms and Plan 3 deliverables in writing.
- Add your own logo or screenshots only when ready; the hero dashboard is a CSS illustration.
- Do not add API keys, broker secrets, or OAuth client secrets to this public repository.

## Important
This is a marketing website only. It does not execute trades, connect to brokers, store customer information, or provide live trading signals.
